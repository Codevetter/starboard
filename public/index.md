# Starboard

GitHub stars organizer, repository discovery surface, and semantic search product.

## Public without sign-in

- Browse and search the seeded Discover corpus
- Inspect detected tool and framework intelligence
- Read the product history, scope, privacy policy, and terms

## With GitHub sign-in

- Sync and organize personal stars with tags and collections
- Connect public GitHub projects for explained repository recommendations
- Search and organize a personal starred-repository library

## Agent entrypoints

- https://starboard.codevetter.com/llms.txt
- https://starboard.codevetter.com/api/ai
- https://starboard.codevetter.com/index.md
